# 《月森关系地图》24 题文案 V3：人际关系版

> 状态：内容已确认；由 Django Migration `tests.0004_publish_human_relationship_v3` 发布为 V3。  
> 核心目标：测试人与人相处时的行为倾向和回应需要；动物与月森只负责视觉隐喻。  
> 产品边界：娱乐化关系倾向探索，不用于心理诊断、伴侣筛选或关系优劣判断。

## 1. V3 的修订原则

1. 题干发生在真实的人际关系中，不再要求用户代入动物、树洞、吊桥或魔法道具。
2. 画面可以保留月森动物，但动物只是情绪和关系状态的旁观者或象征。
3. 图片不能把四个选项一一画出来，避免用户根据画面线索作答。
4. 每章 6 题，其中 3 题测“我通常怎么做”，3 题测“我希望 TA 怎么回应”。
5. “行为”和“需要”分别保留信号，未来双人报告可比较 A 的行为是否回应 B 的需要，反之亦然。
6. 四个选项都代表现实中成立的倾向，不设置明显正确答案。
7. 本文只定义内容结构，不定义权重、分数或正式匹配算法。

## 2. 用户看到的开场文案

### 主标题

> 月森关系地图

### 副标题

> 24 个真实的相处瞬间，看看你怎样靠近一个人，又希望怎样被回应。

### 答题提示

> 这里没有标准答案。  
> 不用选择看起来最成熟的做法，只选最接近你真实反应的那一个。

### 动物说明

> 画面里的动物只是月森中的故事角色，不代表你，也不会提示答案。旅程结束后，动物原型才会作为结果隐喻出现。

## 3. 第一章：靠近与空间

### Q01 意外空出来的下午

**题型**：行为 B

**题目**

> 一个周末下午突然空了出来。你第一时间更想和 TA 怎么安排？

**选项**

- A：一起去一个都没去过的地方
- B：找个舒服的位置，慢慢待上一下午
- C：待在同一个空间里，各做各的事情
- D：先各自安排，晚一点再交换今天的故事

**观察方向**：共同探索、安静陪伴、平行相处、独立后重聚。  
**双人对照**：可与对方 Q04、Q22、Q24 的相处需要对照。  
**画面关系**：保留湖边与动物场景，仅表达“不同方向都可以”，不突出小船、野餐或树屋为答案提示。

### Q02 迟迟没有回音的消息

**题型**：行为 B

**题目**

> 你给 TA 发了一条很想分享的消息，过了很久还没有回复。你通常会怎么做？

**选项**

- A：再发一句，确认 TA 有没有看到
- B：先等一等，TA 忙完自然会回复
- C：继续做自己的事，不让注意力一直停在那里
- D：等下次见面再问，避免一个人反复猜测

**观察方向**：主动确认、信任等待、自我调节、当面澄清。  
**双人对照**：可与对方 Q05、Q06 的确认和空间需要对照。  
**画面关系**：树洞与信使只象征“等待回应”，用户不是画面中的动物。

### Q03 第一时间想分享的开心

**题型**：行为 B

**题目**

> 你刚刚遇到一件很开心的事，第一时间会怎样和 TA 分享？

**选项**

- A：马上发消息或打电话，边说边表达兴奋
- B：先留在心里，等见面时认真告诉 TA
- C：直接邀请 TA 一起参与，让开心变成共同经历
- D：发一张照片或留下线索，等 TA 主动发现

**观察方向**：即时表达、郑重分享、共同体验、含蓄表达。  
**双人对照**：可与对方 Q05、Q21 的被重视方式对照。  
**画面关系**：发光贝壳只象征“想分享的开心”，不作为用户实际选择。

### Q04 比想象中热闹的聚会

**题型**：需要 N

**题目**

**观察方向**：持续连接、独立社交、低刺激适应、双人空间。  
**双人对照**：重点对照对方 Q01、Q19 的行动倾向。  
**画面关系**：灯会只提供人群密度和氛围，不把某只动物表现成正确陪伴者。

### Q05 一段暂时见不到的日子

**题型**：需要 N

**题目**

**选项**

**双人对照**：重点对照对方 Q02、Q03 的联系和表达行为。

### Q06 想独处的一天

**题型**：需要 N

**双人对照**：重点对照对方 Q02、Q22、Q24 对空间和重连的处理。  
**画面关系**：关灯树屋象征个人空间，不让用户代入树屋中的动物。

### Q08 疲惫的一天结束后

### Q09 一句听起来不像“没事”的没事

**观察方向**：主动追问、稳定在场、行动照顾、延迟回应。  
**双人对照**：重点对照对方 Q10、Q11 的情绪边界。  
**画面关系**：芦苇和薄雾象征“情绪还没有说出口”。

### Q10 只想安静缩起来的时候

**观察方向**：被理解、获得帮助、安静陪伴、自主恢复。  
**双人对照**：重点对照对方 Q07、Q08、Q09 的实际回应方式。

### Q11 一件 TA 不太理解的小事

**题型**：需要 N

### Q12 低谷里最想听的一句话

## 5. 第三章：分歧与修复

### Q13 讨论越来越急

**题型**：行为 B

**题目**

> 你和 TA 的讨论越来越急，双方都开始听不进对方的话。你更可能先做什么？

**选项**

- A：继续把自己的意思讲清楚，不想带着误会停下
- B：先暂停，但明确约好什么时候继续谈
- C：先说“我现在有点受伤”，让 TA 看见感受
- D：先处理眼前最具体的分歧，其他问题稍后再谈

**观察方向**：即时澄清、约定暂停、情绪表达、问题拆解。  
**双人对照**：重点对照对方 Q15、Q17 的修复需要。  
**画面关系**：摇晃的吊桥只象征沟通失衡。

### Q14 发现自己误会了 TA

**题型**：行为 B

**题目**

> 争执过后，你发现自己刚才误会了 TA。你更可能怎么做？

**选项**

- A：直接说“是我弄错了，对不起”
- B：先解释自己为什么会那样理解，再认真道歉
- C：不说太多，先用行动把造成的问题修正
- D：先用一点轻松的方式缓和尴尬，再认真道歉

**观察方向**：直接认错、解释后修复、行动修复、幽默修复。  
**双人对照**：重点对照对方 Q15、Q18 对“和好成立”的判断。  
**画面关系**：倒转地图象征误解，不作为实际事件。

### Q15 关系磕碰之后

**题型**：需要 N

**题目**

- B：TA 真正明白你为什么会受伤
- C：TA 说明以后会具体做出什么改变
- D：TA 主动靠近，让两个人先恢复连接

**观察方向**：语言道歉、理解伤害、行为承诺、亲密修复。  
**双人对照**：重点对照对方 Q13、Q14、Q16 的修复行为。  
**画面关系**：踏脚石象征关系中断后的重新连接。

### Q16 同一个问题又出现

**题型**：行为 B

**题目**

> 你们以为已经解决的问题再次出现。你更倾向怎样处理？

**选项**

- A：重新定一条更清楚的规则，并认真执行
- B：一起寻找它为什么总在相似的位置发生
- C：双方各调整一点，形成都能接受的新方案
- D：承认有些差异很难消失，讨论怎样与它共存

**观察方向**：规则建立、深层原因、折中协商、差异接纳。  
**双人对照**：重点对照对方 Q15、Q18 对持续改变的需要。  
**画面关系**：漏水木坝象征重复出现的问题。

### Q17 争吵后的沉默

**题型**：需要 N

**题目**

- D：先分别想清楚，谁准备好谁先开口

**观察方向**：即时修复、约定暂停、非语言连接、自主重启。  
**双人对照**：重点对照对方 Q13、Q16 的冲突节奏。  
**画面关系**：篝火两侧的距离只象征争吵后的沉默。

### Q18 怎样才算真的和好

**题型**：需要 N

**题目**

**观察方向**：认知闭环、亲密连接、共同活动、行为验证。  
**双人对照**：重点对照对方 Q14、Q16 的修复方式。

## 8. 未来双人报告可以回答什么

在正式算法尚未设计前，只确定报告问题，不确定权重：

1. A 常用的靠近方式，是否接近 B 希望收到的方式？
2. B 常用的情绪支持，是否能被 A 感知为支持？
3. 两个人的冲突速度和暂停需求是否容易对上？
4. 双方对独立空间、共同活动和生活计划的节奏是否接近？
5. 哪些差异是可以互补的，哪些差异需要明确翻译？

报告不应只给一个“高或低”的总分，而应输出：

- 自然顺畅区：不需要太多解释就容易对上的部分。
- 需要翻译区：做法不同，但解释后可以理解的部分。
- 容易误会区：A 的好意可能无法被 B 识别的部分。
- 可执行建议：具体到联系、安慰、暂停和共同安排。
