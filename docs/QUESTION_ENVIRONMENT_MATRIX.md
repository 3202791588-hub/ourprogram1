# 《月森关系地图》24题环境与天气分配表

## 使用原则

- 视觉统一来自水彩叠色、轻彩铅、纸张颗粒、动物比例、主体尺度与UI安全区，不来自重复的月夜背景。
- 采用“受控随机”：相邻题不使用相同时间与天气；同一种组合最多出现两次；天气必须服务题意。
- 月亮只在确有叙事需要的题目出现。白天仍属于“月森”世界，不强行加入月亮、星星或萤火。
- 每题只保留一个主光源。题目文字、选项文字和进度始终由代码渲染。
- 底部角落装饰必须随场景变化，不复用固定灌木模板；只在极端边缘放置1–2类低对比元素，不包围中央文字区。

## 多样性统计

- 明确环境/天气组合：24种。
- 时间段：清晨/黎明、上午、中午、下午、日落、黄昏、蓝调时刻、夜晚，共8类。
- 天气与空气状态：晴、阴、多云、有风、小雨、雨后、薄雾、小雪、暴雨将至等，超过8类。
- 夜景题：Q07、Q12、Q17，共3题；蓝调时刻Q05不按纯夜景处理。
