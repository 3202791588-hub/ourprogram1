# 《月森关系地图》24 题场景美术制作规范

> 文档状态：视觉方向确认稿 / 题目与场景第一版  
> 适用范围：微信小程序答题页插画、选项点缀、轻动效与素材验收  
> 当前边界：本文件只定义内容和美术表达，不定义正式人格计分算法，也不生成 AI 报告。

## 1. 设计目标

《月森关系地图》是一套娱乐化的关系倾向测试。用户通过 24 个日常情境完成一次“月光森林旅程”，最终得到主动物原型、副动物原型以及双人关系报告。

答题页应同时满足以下目标：

1. **有故事感**：每一题是一幅不同的月森绘本场景，而不是更换文字的同一张背景。
2. **有统一性**：24 幅画属于同一个世界，笔触、色彩、光源、动物比例和 UI 安全区保持一致。
3. **不暗示答案**：题目中的动物是情境演员，不代表用户的动物结果，也不对应某个选项的好坏。
4. **阅读优先**：插画服务题目，不压住题目和选项；文字全部由小程序代码渲染，不烘焙进插画。
5. **克制治愈**：画面温柔、成熟、安静，不幼儿化、不玄学化、不堆砌星月元素。

## 2. 核心叙事设定

### 2.1 月森世界

“月森”不是现实森林的写实复刻，而是一处由月光、道路、树屋、湖泊、营地和萤火构成的情绪空间。用户每回答一题，就像在森林中走过一个新的岔路。

建议在开始页说明：

> 森林里的动物会陪你经过不同情境，它们不代表你的答案。旅程结束后，你的动物原型才会出现。

### 2.2 动物的角色边界

- 答题插画里的动物是固定的“情境角色”。
- 同一道题始终使用同一场景和同一组动物，不在运行时随机更换。
- 用户的主动物和副动物只在结果页正式揭晓。
- 不让某一种动物长期扮演“正确、成熟、付出者”，另一种长期扮演“错误、任性、被照顾者”。
- 动物行为是关系隐喻，不宣称符合真实动物学行为。

## 3. 统一视觉系统

### 3.1 风格关键词

- 成人向治愈绘本
- 水彩叠色与轻彩铅纹理
- 月光、薄雾、植物和纸张颗粒
- 低饱和蓝绿＋暖象牙白＋少量珊瑚色
- 大面积留白、安静、轻盈、可呼吸
- 叙事明确，但不过度戏剧化

### 3.2 基础色彩

| 用途 | 建议色彩 | 使用原则 |
|---|---|---|
| 夜空/远景 | 雾霾蓝、灰蓝 | 不使用高纯度深蓝或荧光紫 |
| 植物/近景 | 鼠尾草绿、灰松绿 | 深浅靠水彩叠色，不靠纯黑阴影 |
| 页面留白 | 暖象牙白、纸张白 | 保留轻微纸纹，不做纯白数字界面 |
| 月光 | 奶油白、淡月金 | 只承担主要光源和少量引导 |
| 选中状态 | 低饱和珊瑚橙 | 每屏仅一个主要暖色焦点 |
| 文字 | 墨绿黑、暖灰 | 正文避免纯黑，保证对比度 |

### 3.3 光线规则

- 一幅画只设置一个明确主光源：月亮、篝火、窗灯或萤火群。
- 月亮不必每题完整出现，可以是月光、倒影或窗外光斑。
- 萤火是点缀，不得铺满画面。
- 暖光只用于关键关系动作或选中反馈，不用于同时照亮四个答案。

### 3.4 构图与 UI 安全区

- 设计比例以 `390 × 844` 的手机竖屏为基准。
- 插画建议输出不含任何题目文字、按钮文字和进度文字的纯场景版本。
- 主要动物和叙事动作集中在画面上半部约 45%–52%。
- 问题区域应留出连续、低纹理的呼吸空间。
- 四个选项沿道路分枝排布，保持左右不完全对称，避免形成蝴蝶翅膀或四瓣花。
- 选项区域允许少量无边界薄雾、脚印、枝叶线稿和萤火，不使用封闭卡片边框。
- 所有关键动物头部、眼睛、月亮、指示牌不得落入状态栏或底部手势区域。

### 3.5 已确认的答题 UI 语言

- 保留初版的暖象牙白文字区域和道路分枝排版。
- 每个答案位于一条独立支路附近，而不是四张纵向卡片。
- 选中状态使用珊瑚色文字、小对勾和 3–5 枚脚印。
- 可加入的点缀：极淡枝叶线稿、2–3 点萤火、最多 2 个四角月光闪点。
- 不加入全屏重毛玻璃、明显景深模糊、发光花瓣边框或大面积透明面板。

## 4. 全局设计禁忌

以下禁忌适用于全部 24 幅画：

1. 不使用幼儿绘本式大头、腮红、夸张表情和拟人服装堆砌。
2. 不使用塔罗牌、十二星座符号、水晶球、占卜阵等玄学视觉。
3. 不使用高饱和霓虹紫、荧光蓝、纯红或强赛博渐变。
4. 不把选项画成四个封闭圆角卡片、花瓣、翅膀或气泡。
5. 不让四个选项形成严格镜像或中心放射对称。
6. 不在插画中生成题目、选项、进度、按钮或品牌文字。
7. 不用爱心数量代表爱得多或少；爱心只可作为极少量通用图标。
8. 不用破碎、坠落、黑影等强负面符号惩罚某个选项。
9. 不让动物哭得过度悲伤或发生激烈攻击，避免给轻测试增加压力。
10. 不在每题重复完整月亮、满天星星、脚印和萤火；元素应按场景取舍。
11. 不把动物类型和答案位置绑定，例如不能永远让“猫”代表独处选项。
12. 不为了画面丰富填满所有空白，留白本身是设计的一部分。

## 5. 24 道题逐题场景制作

### 第一章：怎样靠近一个人

#### Q01 周末突然空出一天，你更希望两个人怎么过？

- **场景概念**：清晨后的月森岔路，狐狸与水獭站在写有“远行”和“慢慢走”的木牌前。
- **设计思路**：用道路选择表现“探索、安静陪伴、居家和独立安排”之间的节奏差异。
- **主要构图**：远处淡月和森林占上半部；两只动物一左一右面对岔路；道路向下延伸为选项分枝。
- **可添加元素**：折起一角的小地图、露珠、1–2 点晨光萤火、远处树屋烟囱。
- **轻动效**：树叶轻摆；选中后对应道路出现短暂月光流动。
- **本题禁忌**：不要把某条路画得明显更明亮、更安全或更漂亮。

#### Q02 对方很久没有回复消息，你通常会怎么做？

- **场景概念**：黄昏树洞邮局，兔子坐在树根旁，猫头鹰信使从远处飞来。
- **设计思路**：表现等待中的不同节奏，而不是制造被抛弃的焦虑。
- **主要构图**：树洞位于上方偏左，空出的天空和缓坡承担问题区域；四条细小足迹通往不同方向。
- **可添加元素**：未封口的树叶信笺、安静的沙漏果实、低亮度灯笼、远处飞鸟剪影。
- **轻动效**：信笺边角轻动；进度脚印缓慢出现。
- **本题禁忌**：不要出现手机、红色未读数字、哭泣或暴雨。

#### Q03 遇到特别开心的事情，你更倾向于怎样分享？

- **场景概念**：雨后日出时的冷水海湾，海豚从水中平静探出头部，企鹅站在岸边礁石上与它共同回应水面变化。
- **设计思路**：用“立刻分享、见面再说、共同庆祝、等待被问起”表现喜悦的表达方式。
- **主要构图**：海豚身体保持在水下，只露出头部和少量背部；企鹅保持正常鳍肢和蹼足站姿；海面倒影向下分成四道柔和波纹。
- **可添加元素**：贝壳、海草、细浪、两只远处海鸟、少量水面亮点。
- **轻动效**：水面涟漪；选中后对应波纹泛起暖光。
- **本题禁忌**：不要把海面做成高饱和热带蓝，不要加入烟花和大量彩带；不要给企鹅画手指、抓握动作或人类手臂。

#### Q04 一起参加不熟悉的聚会时，你更喜欢怎样相处？

- **场景概念**：森林灯会边缘，金毛向灯火处迈出一步，猫安静坐在较暗的石阶上。
- **设计思路**：呈现社交能量差异，同时避免把安静画成孤僻。
- **主要构图**：灯会只作为远景散景；两只动物处在同一画面但朝向不同；下方道路分别通向灯会、安静角落和回家小径。
- **可添加元素**：纸灯、树叶桌牌、远景模糊动物剪影、小杯热饮。
- **轻动效**：灯笼轻晃；暖光缓慢明灭。
- **本题禁忌**：不要绘制拥挤人群，不要让猫显得被排斥或不开心。

#### Q05 当你想念一个人时，你通常会怎么表达？

- **场景概念**：两座相邻山坡，鹿和狼隔着一条浅谷看见彼此的灯。
- **设计思路**：把想念处理成安静的距离感，而不是煽情分离。
- **主要构图**：两侧山坡构成柔和对角线；鹿与狼之间保持连续草坪和薄雾，不绘制岔路、土路或交叉路径；下方暖象牙白区域承载问题与选项。
- **可添加元素**：小灯、飘落的树叶、远处桥影、极淡呼吸状雾气。
- **轻动效**：两盏灯先后亮起；选中反馈只由UI层显示，不在草坪上生成路径。
- **本题禁忌**：不要出现泪滴、破碎心形或距离数字。

#### Q06 对方提出想独处一天，你的第一反应是什么？

- **场景概念**：月森树屋，猫走上独立的小楼梯，棕熊在不远处整理自己的花园。
- **设计思路**：传达“空间不等于疏远”，让独处与连接同时存在。
- **主要构图**：树屋位于上方偏右，花园偏左；两条路线中间保留可见连接桥。
- **可添加元素**：窗边灯、一本合上的书、小喷壶、连接两地的细绳灯。
- **轻动效**：窗灯慢慢亮起；花叶轻晃。
- **本题禁忌**：不要锁门、拉黑、背对哭泣或把独处空间画成黑暗区域。

### 第二章：怎样接住情绪

#### Q07 约会计划临时被打乱，你第一反应会是什么？

- **场景概念**：已确认视觉基准场景。狐狸与水獭站在森林岔路口，木牌分别指向“随性应变”和“重新规划”。
- **设计思路**：用真实道路分枝连接四个答案，突出变化发生后的应对节奏。
- **主要构图**：森林、动物和月亮集中在上半部；下半部使用暖象牙白留白和不对称道路分枝。
- **可添加元素**：3–5 枚选中脚印、极淡枝叶线稿、2–3 点萤火、最多 2 个小闪点。
- **轻动效**：选项完成后脚印沿所选道路前进，末端出现小对勾。
- **本题禁忌**：不得增加全屏背景、封闭玻璃边框、蝴蝶翅膀式四瓣结构或明显景深模糊。

#### Q08 你很疲惫地回到家，更希望对方怎么做？

- **场景概念**：雨后木屋门口，一只兔子守在门廊台阶旁的暖灯附近，鹿刚从湿润小路回来。
- **设计思路**：表现倾听、解决、拥抱和空间四种支持方式，没有哪一种天然更正确。
- **主要构图**：暖窗与冷色雨林形成温差；兔子自然坐在门廊上，体型明显小于小路上的鹿；动物之间留出适度距离；屋檐下的干燥空间承担问题。
- **可添加元素**：湿伞叶、毛巾、热饮蒸汽、屋檐滴水。
- **轻动效**：雨滴减少；热气轻升；选中后对应门前小径发亮。
- **本题禁忌**：兔子不得拟人化站立、用前爪提灯或大于鹿；不要让兔子直接替鹿完成所有事情，不要出现病弱或医疗暗示。

#### Q09 对方看起来不开心，却说“没事”，你会怎么做？

- **场景概念**：薄雾湖岸，鹿站在芦苇后，猫头鹰停在不远处的低枝上。
- **设计思路**：用雾和可见距离表现“靠近、等待、行动和暂时留白”。
- **主要构图**：鹿不完全被遮住；猫头鹰与鹿保持视线连接；水面倒影向下形成选择路径。
- **可添加元素**：一片落在水面的叶子、细小涟漪、低亮度萤火。
- **轻动效**：雾缓慢移动；水面轻微波动。
- **本题禁忌**：不要把鹿画成哭泣，不要用黑雾表示负面情绪。

#### Q10 当你陷入低落时，最不希望听到哪句话？

- **场景概念**：风停后的草坡，兔子蜷坐在一块暖石旁，水獭把一片大叶子放在附近遮风。
- **设计思路**：强调被理解与被干预之间的界限，画面安静但不沉重。
- **主要构图**：两只动物不直接拥抱；留出一段可选择的靠近距离；草坡曲线进入下方选项区。
- **可添加元素**：落下的蒲公英、叶片遮棚、小石堆、远处微亮天际。
- **轻动效**：蒲公英轻移；选中后一处风纹停止。
- **本题禁忌**：不要出现乌云压顶、眼泪、碎裂物或明显悲伤表演。

#### Q11 对方因一件你不理解的小事难过，你会怎么回应？

- **场景概念**：月池旁，海豚从水中探头，猫头鹰在岸边观察一片沉入水中的发光羽毛。
- **设计思路**：同一件小事可以在两个人心中拥有不同重量。
- **主要构图**：水面一侧开阔、一侧有树影；发光羽毛是视线焦点，但不指向某个正确选项。
- **可添加元素**：羽毛、倒影、浅水石、少量星点。
- **轻动效**：羽毛缓慢下沉；水纹扩散。
- **本题禁忌**：不要使用天平、评分、大小对比来判断情绪是否合理。

#### Q12 你认为最有力量的安慰更接近什么？

- **场景概念**：夜路营灯，狼背着一捆木枝，棕熊在前方为一盏小灯添火。
- **设计思路**：将理解、陪伴、解决和承担表现为不同形式的“照亮道路”。
- **主要构图**：暖灯位于两只动物之间；道路下行后自然分为四种光线方向。
- **可添加元素**：木枝、灯罩、石路、远处营地轮廓。
- **轻动效**：灯火轻闪；选中后对应光线延长。
- **本题禁忌**：不要让力量等于体型，不要把棕熊或狼固定成更可靠的一方。

### 第三章：怎样面对分歧与修复

#### Q13 一场争论开始升温时，你通常会怎么做？

- **场景概念**：风中的吊桥，两只狼分别站在桥的两端，桥面仍然完整连接。
- **设计思路**：分歧是连接中的摇晃，不是关系断裂。
- **主要构图**：吊桥形成横向张力；桥下雾气提供文字留白；下方四条绳结纹路对应不同处理方式。
- **可添加元素**：轻摆绳索、落叶、固定桥面的木钉、远处月光。
- **轻动效**：桥轻微摇晃后稳定；选中后一个绳结亮起。
- **本题禁忌**：不要画断桥、坠落、咆哮、露牙或攻击姿态。

#### Q14 发现自己误会了对方，你更可能怎么处理？

- **场景概念**：狐狸与猫头鹰围着一张倒放的森林地图，转正后道路重新连通。
- **设计思路**：误会来自视角偏差，而不是谁更聪明。
- **主要构图**：地图位于两只动物之间；上方林路与地图线条呼应；下方选项沿四条校正后的线延伸。
- **可添加元素**：小指南针、折痕、铅笔状树枝、擦淡的旧路线。
- **轻动效**：地图轻转；一条错误路线淡出。
- **本题禁忌**：不要使用红叉、问号堆叠或“真相揭晓”式强戏剧效果。

#### Q15 你更希望对方怎样道歉？

- **场景概念**：浅溪中的踏脚石，鹿停在一侧，金毛把一块偏移的石头推回稳定位置。
- **设计思路**：道歉不仅是语言，也可能是理解、行动与重新连接。
- **主要构图**：踏脚石自上而下延伸；水面留白承载问题；四组水纹分隔答案。
- **可添加元素**：一小枝白花、湿润石面、溪边苔藓、倒影。
- **轻动效**：石头归位后水纹平静；选中水纹泛暖光。
- **本题禁忌**：不要让金毛呈跪拜姿势，不要加入夸张礼物或巨大爱心。

#### Q16 同一个问题反复发生时，你倾向于怎样处理？

- **场景概念**：两只河狸修补一座反复漏水的小木坝，旁边放着不同方案的树枝模型。
- **设计思路**：表现规则、需求、妥协和接受差异四种长期处理方式。
- **主要构图**：水坝位于上半部偏侧，不遮挡动物互动；水流分为四条温和支路。
- **可添加元素**：树枝模型、平整石块、测量绳、漂浮叶片。
- **轻动效**：漏水点减少；选择后对应支流水面稳定。
- **本题禁忌**：不要把场景画成工程教学图，不要加入复杂工具和数字标尺。

#### Q17 争吵后的夜晚，你更希望怎样度过？

- **场景概念**：篝火两侧，猫在树根旁安静坐着，猫头鹰停在另一侧；火仍未熄灭。
- **设计思路**：画面保留联系，但允许不同的冷静距离。
- **主要构图**：微弱篝火处于中心偏上；两只动物不背对观众；下方烟雾轨迹转化为选项分枝。
- **可添加元素**：两只杯子、未烧完的木枝、柔和烟线、远处营帐。
- **轻动效**：火光缓慢呼吸；选中后一条烟线变清晰。
- **本题禁忌**：不要让篝火熄灭，不要出现背包离开、关门或孤立黑影。

#### Q18 和好以后，你最需要什么？

- **场景概念**：雨后小船重新靠岸，水獭系好绳结，棕熊把一块湿木板铺成上岸通道。
- **设计思路**：修复既包括语言和接触，也包括重新共同做事和看到改变。
- **主要构图**：船、岸和绳结形成三角关系；水面下方留出四条柔和倒影路径。
- **可添加元素**：绳结、湿木板、放晴云层、岸边小花。
- **轻动效**：水滴落下；绳结收紧；倒影恢复平稳。
- **本题禁忌**：不要画沉船、破洞或过于危险的水面。

### 第四章：怎样一起生活

#### Q19 你理想中的周末节奏更接近哪一种？

- **场景概念**：湖谷清晨，狐狸准备走向远处小径，海豚在近岸水面绕圈，两条路线最终汇合。
- **设计思路**：表现探索、稳定、随性以及“一起与分开”的时间分配。
- **主要构图**：山谷和湖面各占一侧；中间留出连接空间；下方路径不规则分枝。
- **可添加元素**：小背包、岸边毯子、远处熟悉木屋、轻云。
- **轻动效**：水面闪光；云影缓慢移动。
- **本题禁忌**：不要让远行路线比留在原地更宏伟或更有奖励感。

#### Q20 两个人旅行时，你更舒服的方式是什么？

- **场景概念**：两只白兔伏坐在雪山车站旁共同查看地图，附近还有简单路标和未标记小径。
- **设计思路**：把计划精度差异转化为空间信息密度差异。
- **主要构图**：车站顶棚形成上方框景；两只体型相近、比例自然的白兔位于地图两侧；下方道路由规整逐渐过渡到自由曲线。
- **可添加元素**：行李牌、简化时刻牌、指南针、远处积雪松林。
- **轻动效**：纸地图轻摆；远处松枝轻晃。
- **本题禁忌**：白兔不得拟人化站立、用前爪指地图或出现人手；插画内不要出现可读时刻文字，不要画现代大型交通枢纽。

#### Q21 对纪念日，你更在意什么？

- **场景概念**：两只企鹅在冷水岩岸边整理几颗有时间痕迹、无数字的深色扁平卵石。
- **设计思路**：表达准备、记得、自然和日常陪伴之间的差异，避免消费主义。
- **主要构图**：深色扁平卵石形成不规则松散关系；一只企鹅用喙轻触卵石，另一只看向远处海岸；水面承担留白。
- **可添加元素**：低矮海岸草、少量冲上海岸的海藻、远处海崖、岩石纹理。
- **轻动效**：一颗月光石渐亮；湖面轻微反射。
- **本题禁忌**：不要出现戒指、昂贵礼盒、烛光晚餐模板或婚礼暗示；卵石不得呈白色蛋形，不出现蛋、巢、偷取姿势、企鹅手指或人类抓握动作。

#### Q22 当两个人兴趣不同，怎样相处更舒服？

- **场景概念**：猫在树屋看书，海豚在下方溪流玩水，中间有一处共同分享的小平台。
- **设计思路**：让各自世界与共同区域同时可见。
- **主要构图**：上下错层而非左右对立；平台位于视觉中点；四条路线分别通往独处、体验、共同兴趣和回来分享。
- **可添加元素**：书页、漂浮球果、平台上的两只杯子、连接绳灯。
- **轻动效**：书页轻翻；水面小幅跃动；平台灯亮起。
- **本题禁忌**：不要把读书画成更高级，也不要把玩水画成幼稚。

#### Q23 面对重要的共同决定，你更依赖什么？

- **场景概念**：猫头鹰与河狸在长桌前查看森林地图、天气云图和两枚代表感受的暖石。
- **设计思路**：同时呈现事实、感受、经验主导和共同安心四种决策依据。
- **主要构图**：桌面只占上半部一小块，避免数据界面感；下方四条桌布纹路自然延伸为答案。
- **可添加元素**：地图、云纹卡片、暖石、空白便签叶片。
- **轻动效**：暖石微亮；地图边角轻动。
- **本题禁忌**：不要画图表、评分条、计算器或商务会议场景。

#### Q24 如果把理想关系想象成一段森林旅程，你更喜欢哪一种？

- **场景概念**：旅程终章。两只不指向任何特定结果的动物剪影，走向月光下的四种道路关系：并肩、轮流领路、分开后汇合、共同搭营。
- **设计思路**：作为情绪收束和结果揭晓前的过渡，不直接暴露动物类型。
- **主要构图**：远景营地和月光形成终点；道路在中景清楚区分、远景再次汇合；保留大面积安静天空。
- **可添加元素**：一盏营灯、尚未完全搭好的帐篷、两组脚印、远处湖面。
- **轻动效**：回答后脚印继续走向营地；月光短暂增强，再进入结果页。
- **本题禁忌**：不要把某条路线设置为唯一到达营地的道路，不要提前出现用户结果动物或契合度数字。

## 6. 轻动效统一规范

轻动效的作用是确认操作、延续旅程，不是制造游戏特效。

### 6.1 每题允许的动效

- 环境循环动效：最多 1–2 个，例如树叶轻摆、灯火呼吸、湖面涟漪。
- 选择反馈：选中文字变为珊瑚色，3–5 枚脚印依次出现，末端出现小对勾。
- 页面过渡：脚印走出当前支路后淡出，再进入下一题。
- 单次答题反馈建议控制在约 300–500ms，不阻塞用户继续操作。

### 6.2 动效禁忌

- 不使用撒花、爆炸粒子、大面积星光雨。
- 不让动物因某个选项出现夸张开心或失望反应。
- 不使用连续晃动、弹跳或高频闪烁。
- 不用动效延长答题时间或掩盖接口等待。
- 低性能设备或用户开启减少动态效果时，应能关闭环境动效，只保留必要选择反馈。

## 7. 素材制作与工程交付

### 7.1 插画素材分层

推荐每题至少拆成以下层级：

1. `background`：天空、远山、森林、水面。
2. `midground`：道路、树屋、桥、湖岸等主要场景。
3. `characters`：动物角色与关键道具。
4. `foreground`：近景枝叶、石头、低对比装饰。
5. `effects`：萤火、月光、脚印等可选择性动效元素。
6. `ui`：题目、答案、进度、选中反馈，由 WXML/WXSS 渲染，不合入位图。

如果首版开发成本需要降低，可以把 `background + midground + characters + foreground` 合成为一张静态 WebP，只单独保留少量 `effects` 动效层。

### 7.2 命名规范

```text
assets/questions/q01/background.webp
assets/questions/q01/scene.webp
assets/questions/q01/effect-fireflies.webp
assets/questions/q01/effect-paw-selected.webp
```

建议通过题目 `metadata` 或独立清单维护资源映射，不把路径散落写死在页面逻辑中：

```json
{
  "questionId": 1,
  "sceneKey": "free_day_crossroads",
  "sceneAsset": "q01/scene.webp",
  "accent": "coral",
  "motionPreset": "leaves-and-path"
}
```

### 7.3 输出要求

- 按 `390 × 844` 比例设计，保留高分辨率母版。
- 位图优先输出压缩后的 WebP；透明小元素单独输出透明 WebP 或 PNG。
- 禁止在最终素材中保留生成式图片水印、随机文字和不可控符号。
- 同一题的不同素材必须共享相同构图坐标，避免真机切换时跳动。
- 当前题加载时预取下一题素材；不得一次性把 24 张大图全部塞入首屏。
- 网络加载失败时提供统一的低体积月森占位背景，不能阻断答题。

## 8. 插画/生成提示词母版

每道题可在下列母版基础上替换场景描述：

```text
用途：微信小程序关系测试答题页纯插画背景，不包含任何 UI 文字。
画幅：390:844 手机竖屏比例，全画面绘本插画。
场景：<本题场景、动物、动作、时间、地点>。
叙事目标：<本题希望表达的关系情境>，不暗示任何选项更正确。
构图：主要动物集中在上半部；问题和四个分枝选项区域保留低纹理安全区；道路向下延伸但不形成左右严格对称。
风格：成人向治愈绘本，水彩叠色与轻彩铅纹理，低饱和雾霾蓝、鼠尾草绿、暖象牙白和少量月光金。
光线：一个明确主光源，暖光克制，萤火不超过少量点缀。
必须避免：文字、字母、数字、水印、Logo、幼儿卡通、霓虹色、塔罗占卜、封闭选项卡片、蝴蝶翅膀式构图、密集星星、过度戏剧化表情。
```

## 9. 单题验收清单

每幅画进入小程序前，至少检查以下项目：

- [ ] 场景与题意相符，但没有暗示标准答案。
- [ ] 动物只是故事角色，没有提前代表用户结果。
- [ ] 与其他题有明显不同的地点、动作或叙事道具。
- [ ] 仍然属于统一的月森世界和同一套绘本画风。
- [ ] 问题、选项和进度安全区足够，背景纹理不会影响阅读。
- [ ] 四条选项支路不形成严格对称、花瓣或蝴蝶轮廓。
- [ ] 点缀数量克制，不抢问题与选项。
- [ ] 插画中没有随机文字、乱码、水印或品牌标识。
- [ ] 选中、未选中状态均能保持足够文字对比。
- [ ] 真机窄屏和长屏裁切后，动物头部及关键道具仍完整。
- [ ] 素材体积、加载、预取和失败占位策略已验证。
- [ ] 动效不会阻塞连续快速答题。

## 10. 后续制作顺序

1. 先制作 Q07 作为风格基准图和真机 UI 样板。
2. 再制作差异较大的 Q03（月光海湾）、Q13（吊桥）、Q21（月湖纪念日）验证跨场景一致性。
3. 四张样板通过后，批量制作其余 20 题。
4. 每完成 6 题进行一次统一性检查，不等 24 题全部完成后再返工。
5. 24 题美术验收后，再制作 12 种结果动物主插画与副动物符号。
6. 正式动物计分与双人关系文案另行评审，不在本美术规范中提前写死。
